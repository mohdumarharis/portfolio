01 — APPLIED AI IN PRODUCTION

A recovery call.
A clearer next step.

Turning call recordings into summaries, case details and recommended actions, so recovery agents can get to the information they need.

CONTEXT
Call Assist Ltd · Insurance & recovery
MY WORK
End-to-end GenAI pipeline, API delivery and deployment
Python / Azure OpenAI / FastAPI / MLflow
Read the project notes ＋

The problem

Manual review meant working through call recordings to find the information needed for a case. The pipeline brings transcription, summarisation, intent and sentiment extraction into one workflow.

What I built

Speech-to-text feeds an LLM pipeline that extracts key case details and generates recovery options and recommended actions. FastAPI serves the outputs, and a Microsoft Copilot chatbot makes the insights available within agent workflows.

Putting it into production

Deployed on Azure, with MLflow for experiment tracking and model versioning, and GitHub Actions for testing and deployment.

Proprietary work. The diagram describes the workflow; it contains no customer recordings or internal system data.
